Short Description

CRMS Enhancement 2026

⸻

Description

As part of the HBSA CRMS Enhancements Project, application, integration and database enhancements are being implemented to support updated business policies, KYC requirements, system integrations, data synchronization and identified application issues.

The change includes the following CH1–CH19 scope:

1. CH1 – KYC Reason / RDD-BDD Policy Update
    Amend KYC Reason to include RDD/BDD as required by the updated policy.
2. CH2 – KYC Renewal Date Calculation
    Enhance KYC renewal date calculation to consider SBM/FCC approval dates.
3. CH3 – RDD/BDD Connected Parties Enhancement
    Enhance the RDD/BDD section to include connected parties information.
4. CH4 – Removal of Redundant Fields
    Remove redundant fields due to the updated policy changes.
5. CH5 – Client Classification Update
    Decommission the existing client classification categories in line with the new policy.
6. CH6 – SCC Classification Enhancement
    Merge SCC classification under the RAM risk assessment section and add the document saving section.
7. CH7 – Final Risk Rating
    Update the RAM risk rating displayed on the profile header to reflect the Final Risk Rating.
8. CH8 – SoW / SoF Enhancement
    Align Source of Wealth (SoW) and Source of Funds (SoF) questions with the new approach.
9. CH9 – Authorized Person / Related Parties Enhancement
    Update authorized person details under Other Related Parties and reflect the connected party table fields.
10. CH10 – Defence Sector Controls
    Add defence sector controls, including sector contribution percentage evaluation and the required KYC approval/stop logic.
11. CH11 – Reduced/Baseline CDD Search Enhancement
    Make Reduced/Baseline CDD information available for search and provide Full Legal Name as a search field.
12. CH12 – WATHQ Integration
    Implement WATHQ API integration to allow users to perform enquiries using the CR number and retain responses for one month, including availability to read-only users.
13. CH13 – Reduced/Baseline CDD Data Synchronization
    Synchronize Reduced/Baseline CDD data to OWS.
14. CH14 – CRMS to OMS Integration Enhancement
    Enhance CRMS to OMS API calls to ensure all required data is passed correctly. Implement email notification when the integration fails.
15. CH15 – CMA List Upload
    Enable CMA list upload into CRMS for availability in OWS.
16. CH16 – WATHQ Fetch Issue Resolution
    Fix WATHQ fetch issues, including incorrect fulfilment alerts and cases where the call does not reach the CRMS Interface API Server.
17. CH17 – Gregorian/Hijri Date Conversion Issue
    Fix date conversion issues between Gregorian and Hijri dates in the calendar.
18. CH18 – FATCA and CRS Field Addition
    Add the required FATCA and CRS fields.
19. CH19 – SMS Failure Notification
    Implement email notification to HBSA when an SMS failure is recorded in the SMS Alert table.

The deployment covers:

* SAS Visual Investigator – Entities, Pages, Workflows and Solution Extensions.

The deployment will follow the approved deployment sequence, including Oracle database updates, PostgreSQL solution extension updates, SAS VI configuration and credential configuration, SAS codes/jobs, scheduled job configuration and required one-time code execution.
